## วิธีใช้แบบฟอร์ม (สำหรับผู้แทนฝ่ายธุรกิจ)

1. อ่าน "สิ่งที่ทดสอบ" ของแต่ละสถานการณ์ แล้วเลือกอย่างใดอย่างหนึ่ง:
   - **ทดสอบด้วยตนเอง** — เดินตาม "ขั้นตอนย่อ" บนเซิร์ฟเวอร์ทดสอบ
     (ทีมพัฒนาจะเปิดเซิร์ฟเวอร์ + บัญชีทดสอบให้ ใช้เวลาสถานการณ์ละ ~5 นาที)
   - **ตรวจสอบจากหลักฐานที่บันทึก** — ดูภาพหน้าจอ + บันทึกผลที่ทีมรันไว้
     (ชุดภาพ `.omc/reports/screenshots/run-2026-09-11T1243Z-e2e/` 46 ภาพ,
     `run-2026-09-11T1255Z-uat/` 8 ภาพ,
     `run-2026-09-11T1344Z-uat2/` 10 ภาพ — ชุด journey-evidence:
     รูปแนบคงอยู่หลังแก้ไข + เหตุผลไทยใน UI, สรุปผล Doc 18 §4-§5)
2. ถ้าผลเป็นไปตามที่ฝ่ายธุรกิจคาดหวัง → ลงชื่อในช่อง "ผู้แทนฝ่ายธุรกิจยอมรับ"
   พร้อมวันที่ ถ้าไม่ผ่านหรือมีข้อสังเกต → จดในช่อง "ข้อสังเกต" (ทีมพัฒนา
   จะบันทึกเป็น finding และแก้ไขก่อนขอยอมรับใหม่)
